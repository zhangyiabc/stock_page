# A 股投资分析系统

基于 [OpenClaw](https://github.com/openclaw/openclaw) 构建的多 Agent A 股投资分析与模拟交易系统，集成飞书群进行实时交互。

       │              ▼
       │         ┌──────────┐

## Agent 一览

| Agent ID | 名称 | Emoji | 模型 | 职责 |
|----------|------|-------|------|------|
| `coordinator` | 盘古 · 协调者 | 🏛️ | kimi-k2.5 | 飞书群交互入口，任务分发，报告组装 |
| `researcher` | 朝闻 · 研究员 | 🔬 | qwen3-max | 五维分析（基本面/技术面/政策/地缘/情绪），选股筛选 |

| `portfolio-mgr` | 算盘 · 持仓管家 | 🧮 | qwen3.5-plus | 自选管理，模拟交易，收益核算，排行榜 |

## 部署步骤

### 1. 安装依赖

```bash
# OpenClaw
npm install -g openclaw@latest
openclaw onboard --install-daemon

# MCP Server 依赖
pip install fastmcp akshare pandas
```

### 2. 复制 workspace 到 OpenClaw 目录

```bash
cp -r workspaces/coordinator/* ~/.openclaw/workspace-coordinator/
cp -r workspaces/researcher/* ~/.openclaw/workspace-researcher/
cp -r workspaces/strategist/* ~/.openclaw/workspace-strategist/
cp -r workspaces/portfolio-mgr/* ~/.openclaw/workspace-portfolio-mgr/
```

### 3. 配置飞书

```bash
openclaw channels add  # 选择 Feishu，输入 App ID 和 App Secret
```

### 4. 修改配置

编辑 `openclaw.json`，替换以下占位符：
- `oc_XXXXXXXX` → 你的飞书群 ID
- `cli_XXXXXXXX` → 你的飞书 App ID
- `XXXXXXXX`（appSecret） → 你的飞书 App Secret

然后复制到 OpenClaw 配置目录：
```bash
cp openclaw.json ~/.openclaw/openclaw.json
```

### 5. 配置定时任务

```bash
chmod +x setup-cron.sh
# 编辑 setup-cron.sh 中的飞书群 ID
./setup-cron.sh
```

### 6. 启动 MCP Server + Gateway

```bash
# 启动 Gateway（MCP Server 由 OpenClaw 通过 stdio 自动启动）
openclaw gateway --port 18789
```
