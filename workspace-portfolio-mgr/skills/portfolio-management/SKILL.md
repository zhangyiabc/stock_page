# A 股模拟持仓管理

管理投资者的虚拟投资组合，执行模拟交易，计算收益。

## 触发条件

收到以下任务指令时使用此 Skill：
- `[REGISTER]` — 注册投资者
- `[ADD_WATCHLIST]` / `[REMOVE_WATCHLIST]` / `[WATCHLIST]` — 自选股管理

## A 股交易规则（模拟严格遵循）

### 基本规则

| 规则项 | 说明 |
|--------|------|
| 交易单位 | 100 股（1 手）的整数倍 |
| 交易制度 | T+1（买入后次一交易日才能卖出）|
| 交易时间 | 9:30-11:30, 13:00-15:00（周一至周五，法定节假日除外）|
| 涨跌停 | 主板 ±10%，创业板(300xxx) ±20%，科创板(688xxx) ±20% |
| 新股首日 | 主板无涨跌停限制但有临停机制，科创/创业板前 5 日无涨跌停 |

### 手续费计算

```
买入费用：
  佣金 = max(成交金额 × 0.00025, 5.00)
  过户费 = 成交金额 × 0.00001（仅沪市 6xxxxx）
  买入总费用 = 佣金 + 过户费

卖出费用：
  佣金 = max(成交金额 × 0.00025, 5.00)
  印花税 = 成交金额 × 0.0005
  过户费 = 成交金额 × 0.00001（仅沪市 6xxxxx）
  卖出总费用 = 佣金 + 印花税 + 过户费
```

### 成本价计算

```
持仓成本价 = (原持仓成本 × 原数量 + 新买入金额 + 买入手续费) / (原数量 + 新数量)
```

### 收益计算

```
浮动盈亏 = (现价 - 成本价) × 持仓数量
浮动收益率 = (现价 - 成本价) / 成本价 × 100%
已实现盈亏 = 卖出金额 - 卖出手续费 - 买入成本
今日盈亏 = (今日收盘价 - 昨日收盘价) × 持仓数量
总资产 = 可用资金 + Σ(持仓市值)
总收益率 = (总资产 - 初始资金) / 初始资金 × 100%
```

## 交易前验证清单

### 买入验证

```
[买入前检查]
1. ✅/❌ 股票代码有效（市场中存在）
2. ✅/❌ 非 ST/*ST（如有风险提醒）
3. ✅/❌ 买入数量为 100 的整数倍
4. ✅/❌ 可用资金 ≥ 买入金额 + 手续费
5. ✅/❌ 当前在交易时间内
6. ✅/❌ 该股未涨停（涨停无法买入）
7. ✅/❌ 该股未停牌
```

### 卖出验证

```
[卖出前检查]
1. ✅/❌ 持仓中有该股票
2. ✅/❌ 持仓数量 ≥ 卖出数量
3. ✅/❌ T+1 检查通过（非当日买入）
4. ✅/❌ 该股未跌停（跌停可能无法卖出）
5. ✅/❌ 该股未停牌
```

## 每日快照流程

收盘后（15:00之后）执行：

1. 获取所有投资者持仓
2. 获取所有持仓股票的收盘价
3. 计算每位投资者的：
   - 今日总资产
   - 今日盈亏金额
   - 今日收益率
   - 累计总收益率
4. 保存快照到数据库
5. 生成收益排行
