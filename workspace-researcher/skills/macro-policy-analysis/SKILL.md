# 宏观政策与地缘政治分析

分析宏观经济政策和地缘政治因素对 A 股个股/行业的影响。

## 触发条件

当收到包含 `[ANALYZE:{股票代码}]` 的消息，且需要政策面/地缘政治分析时使用此 Skill。

## 分析框架

### 一、宏观政策分析

#### 第一步：货币政策

通过 `news-sentiment-mcp` 的 `get_policy_news` 获取央行相关政策。

关注要素：
| 政策信号 | 利好行业 | 利空行业 |
|---------|---------|---------|
| 降准降息 | 银行（短期利空但放量利好）、地产、基建 | 储蓄型产品 |
| 加息收紧 | 银行（净息差扩大）| 高杠杆行业、地产 |
| 定向降准 | 被定向支持的行业（小微、绿色等）| — |
| MLF/逆回购放量 | 流动性敏感板块 | — |

#### 第二步：财政政策

| 政策信号 | 影响路径 |
|---------|---------|
| 专项债加速发行 | 基建→建材/机械/水泥 |
| 减税降费 | 制造业/中小企业利润释放 |
| 消费补贴 | 家电/汽车/消费电子 |
| 新能源补贴 | 光伏/风电/新能源车 |

#### 第三步：产业政策

| 政策类型 | 分析方法 |
|---------|---------|
| 行业规划（如"十四五"）| 识别重点扶持方向，利好相关龙头 |
| 行业准入限制 | 利好已有牌照企业，利空新进入者 |
| 环保/碳排放政策 | 利好清洁能源，利空高污染行业 |
| 反垄断/数据安全 | 利空大型平台企业 |
| 集中采购（医药）| 利空未中标企业，利好中标放量企业 |

#### 第四步：监管政策

| 信号 | 影响 |
|------|------|
| IPO 节奏加快 | 利空小盘股（分流资金）|
| 减持新规收紧 | 利好全市场情绪 |
| 融资融券政策变化 | 影响市场杠杆水平 |
| 印花税调整 | 直接影响交易成本和市场活跃度 |

### 二、地缘政治分析

#### 第一步：中美关系

| 场景 | 影响链条 |
|------|---------|
| 贸易摩擦升级 | 出口型企业承压→人民币贬值→进口替代受益 |
| 科技封锁加码 | 半导体/AI 国产替代加速→利好国内龙头 |
| 关系缓和 | 出口恢复→消费电子/纺织服装受益 |
| 金融制裁风险 | 中概股回流→港股/A 股承接 |

#### 第二步：区域冲突

| 场景 | 影响链条 |
|------|---------|
| 中东冲突 | 油价上涨→利好石油/煤炭→利空航空/化工 |
| 台海局势 | 半导体供应链风险→国产替代逻辑强化 |
| 俄乌局势 | 大宗商品波动→能源/粮食板块 |

#### 第三步：全球经济环境

| 场景 | 影响 |
|------|------|
| 美联储加息/降息 | 影响人民币汇率→北向资金流向 |
| 全球衰退预期 | 避险资产（黄金/公用事业）受益 |
| 大宗商品周期 | 上游资源股周期性机会 |

## 评分标准

| 评分 | 条件 |
|------|------|
| ⭐⭐⭐⭐⭐ | 明确利好政策+行业直接受益+政策持续性强 |
| ⭐⭐⭐⭐ | 政策利好但存在执行不确定性 |
| ⭐⭐⭐ | 政策中性或无直接影响 |
| ⭐⭐ | 存在政策利空但影响有限 |
| ⭐ | 明确政策利空或重大地缘风险 |

## 输出格式

```
▍政策面分析 ⭐⭐⭐⭐ (4/5)

宏观政策：
1. {政策1}：{对该股的影响路径和程度}
2. {政策2}：{对该股的影响路径和程度}
政策方向：{利好/中性/利空}

▍地缘政治分析 ⭐⭐⭐ (3/5)

关键因素：
1. {因素1}：{影响路径和程度}
2. {因素2}：{影响路径和程度}
风险等级：{低/中/高}

核心观点：{一句话总结政策面和地缘对该股的综合影响}
```

## 分析质量要求

- 政策引用需注明具体文件名/会议名/日期
- 地缘分析不做方向预判，只分析"如果发生 X，对 Y 股票的影响是什么"
- 对不确定性高的政策，标注"待观察"
- 区分短期冲击和长期结构性影响
