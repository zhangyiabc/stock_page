# 市场情绪面分析

分析 A 股个股和市场的情绪状态，捕捉预期差和拐点信号。

## 触发条件

- 收到 `[ANALYZE:{股票代码}]` 时进行个股情绪分析
- 收到 `[SENTIMENT_CHECK:{股票列表}]` 时进行批量舆情变化检测

## 分析框架

### 一、个股情绪分析

#### 第一步：舆情扫描

调用 `news-sentiment-mcp` 的 `get_stock_news` 获取近期新闻：
1. 统计正面/中性/负面新闻比例
2. 识别重大事件（财报、并购、诉讼、高管变动等）
3. 评估新闻的市场影响力（来源权重：官方公告 > 券商研报 > 财经媒体 > 自媒体）

#### 第二步：资金流向

调用 `stock-data-mcp` 的 `get_realtime_quote` 获取：
- 主力净流入/流出金额和比例
- 超大单/大单/中单/小单分布
- 连续 N 日主力净流入/流出趋势

资金信号解读：
| 信号 | 含义 | 可靠度 |
|------|------|--------|
| 主力连续3日净流入 | 机构建仓迹象 | 高 |
| 主力单日大额流出 | 可能是获利了结 | 中 |
| 小单持续流入+大单流出 | 散户接盘，谨慎 | 高 |
| 尾盘主力大额流入 | 可能是游资操作 | 低 |

#### 第三步：龙虎榜分析

调用 `stock-data-mcp` 的 `get_top_list`（如有上榜）：
- 买入方：机构专用席位 vs 知名游资席位
- 卖出方：机构 vs 游资
- 净买入金额

机构席位买入 → 利好信号（中长期资金介入）
知名游资买入 → 短期博弈，注意持续性

#### 第四步：融资融券

- 融资余额变化：增加 = 杠杆资金看多，减少 = 去杠杆
- 融券余额变化：增加 = 做空力量增强
- 融资/融券比：> 5 偏多头主导，< 2 空头活跃

#### 第五步：市场整体情绪

调用 `news-sentiment-mcp` 的 `get_market_sentiment`：
- 恐贪指数（如有）
- 涨跌家数比
- 涨停/跌停家数
- 两市成交额（> 1万亿偏活跃，< 6000亿偏冷清）

### 二、批量舆情变化检测

调用 `news-sentiment-mcp` 的 `check_sentiment_change`：

对每只股票，检测以下变化类型：

| 变化类型 | 检测方法 | 紧急度 |
|---------|---------|--------|
| 财报发布 | 新闻关键词匹配 | 高 |
| 业绩预告/快报 | 公告监控 | 高 |
| 重大合同/中标 | 新闻匹配 | 中 |
| 高管变动 | 新闻匹配 | 中 |
| 监管处罚 | 新闻匹配 | 高 |
| 大股东减持公告 | 公告监控 | 高 |
| 行业政策变动 | 关联行业政策匹配 | 中 |
| 评级变化 | 券商研报 | 低 |
| 社交媒体热度异常 | 讨论量突增 | 低 |

变化检测返回格式：
```
[SENTIMENT_CHANGE]
- 600519.SH 贵州茅台：财报发布 | Q1净利润同比+15.3%超预期 | 影响: 正面
- 002594.SZ 比亚迪：高管减持 | 副总裁减持50万股 | 影响: 负面
[NO_CHANGE] 000858.SZ, 601318.SH
```

## 评分标准

| 评分 | 条件 |
|------|------|
| ⭐⭐⭐⭐⭐ | 舆情正面+主力资金持续流入+机构龙虎榜买入 |
| ⭐⭐⭐⭐ | 舆情偏正面+资金面支持 |
| ⭐⭐⭐ | 舆情中性+资金面平稳 |
| ⭐⭐ | 舆情偏负面或资金流出 |
| ⭐ | 重大负面事件+资金大幅流出 |

## 输出格式

```
▍情绪面分析 ⭐⭐⭐⭐ (4/5)

舆情倾向：正面 65% | 中性 25% | 负面 10%
重要事件：{事件摘要}
主力资金：近5日净流入 ¥X.XX亿（连续3日流入）
龙虎榜：近20日上榜1次，机构买入 ¥X.XX亿
融资余额变化：+2.3%（近5日）
市场情绪：两市成交 ¥1.2万亿（活跃）

核心观点：{一句话总结情绪面状态}
```

## 注意事项

- 情绪是最不稳定的维度，权重不宜过高
- 极端情绪往往是反向信号（极度乐观时谨慎，极度恐慌时关注机会）
- 自媒体信息需交叉验证，避免被虚假信息误导
- 龙虎榜数据 T+1 公布，具有滞后性
