# A 股技术面分析

基于 K 线和量价数据，判断股票的趋势方向和买卖时机。所有数据通过 `stock-data-mcp` 获取。

## 触发条件

当收到包含 `[ANALYZE:{股票代码}]` 的消息，且需要技术面分析时使用此 Skill。

## 分析框架

### 第一步：获取数据

调用 `stock-data-mcp`：
1. `get_kline` — 日 K 线数据（至少 250 个交易日）
2. `get_realtime_quote` — 最新实时行情

### 第二步：趋势判断（均线系统）

计算均线：MA5, MA10, MA20, MA60, MA120, MA250

| 形态 | 判断标准 | 含义 |
|------|---------|------|
| 多头排列 | MA5 > MA10 > MA20 > MA60 | 强势上升趋势 |
| 空头排列 | MA5 < MA10 < MA20 < MA60 | 弱势下降趋势 |
| 金叉 | 短期均线上穿长期均线 | 潜在买入信号 |
| 死叉 | 短期均线下穿长期均线 | 潜在卖出信号 |
| 站上 MA250 | 价格 > 年线 | 长期多头格局 |

### 第三步：动量指标

#### MACD (12, 26, 9)
```
DIF = EMA(12) - EMA(26)
DEA = EMA(DIF, 9)
MACD柱 = 2 × (DIF - DEA)
```
- DIF 上穿 DEA → 金叉（买入信号）
- DIF 下穿 DEA → 死叉（卖出信号）
- 零轴上方金叉 → 强势买入
- 零轴下方死叉 → 强势卖出
- 顶背离（价格新高但 MACD 未新高）→ 见顶信号
- 底背离（价格新低但 MACD 未新低）→ 见底信号

#### RSI (6, 12, 24)
```
RS = 平均上涨幅度 / 平均下跌幅度
RSI = 100 - 100/(1+RS)
```
- RSI > 80 → 超买区域（可能回调）
- RSI < 20 → 超卖区域（可能反弹）
- RSI 50 为多空分界线

#### KDJ (9, 3, 3)
- K > 80 且 D > 80 → 超买
- K < 20 且 D < 20 → 超卖
- K 上穿 D → 金叉买入
- K 下穿 D → 死叉卖出
- J > 100 → 极度超买
- J < 0 → 极度超卖

### 第四步：布林带 (20, 2)

```
中轨 = MA(20)
上轨 = MA(20) + 2σ
下轨 = MA(20) - 2σ
带宽 = (上轨 - 下轨) / 中轨
```

| 位置 | 含义 |
|------|------|
| 价格触及上轨 | 短期偏强，可能回调 |
| 价格触及下轨 | 短期偏弱，可能反弹 |
| 带宽收窄 | 即将选择方向，关注突破 |
| 带宽放大 | 趋势加速，顺势操作 |

### 第五步：量价分析

| 形态 | 含义 |
|------|------|
| 价涨量增 | 上涨有资金支持，健康 |
| 价涨量缩 | 上涨动力不足，警惕 |
| 价跌量增 | 恐慌性抛售，关注是否到位 |
| 价跌量缩 | 下跌动力衰竭，可能见底 |
| 地量 | 成交极度萎缩，变盘在即 |
| 天量 | 多空激烈博弈，注意方向选择 |

### 第六步：关键价位识别

- **支撑位**：近期低点、密集成交区下沿、整数关口、均线位置
- **压力位**：近期高点、密集成交区上沿、前期套牢区、均线位置
- **缺口**：向上跳空缺口（支撑）、向下跳空缺口（压力）

## 评分标准

| 评分 | 条件 |
|------|------|
| ⭐⭐⭐⭐⭐ | 多头排列 + MACD金叉 + RSI中性 + 量价配合 |
| ⭐⭐⭐⭐ | 趋势向上 + 至少两个指标积极 |
| ⭐⭐⭐ | 震荡格局，方向不明 |
| ⭐⭐ | 趋势向下但有见底迹象 |
| ⭐ | 空头排列 + 多个指标发出卖出信号 |

## 输出格式

```
▍技术面分析 ⭐⭐⭐⭐ (4/5)

趋势判断：上升趋势（多头排列，站上 MA250）
均线：MA5(XX) > MA10(XX) > MA20(XX) > MA60(XX)
MACD：金叉，红柱放大，DIF=X.XX，DEA=X.XX
RSI(14)：58.3（中性偏多）
KDJ：K=72.1, D=65.3, J=85.7（偏多，接近超买）
布林带：价格在中轨与上轨之间，带宽适中
量价关系：近5日量价齐升，资金介入明显
关键位：支撑 ¥XX.XX（MA20），压力 ¥XX.XX（前高）

核心观点：{一句话总结技术面状态和操作建议}
```

## A 股技术面特殊注意事项

- **涨跌停板效应**：涨停缩量（多方强势锁仓）、跌停放量（恐慌出逃）
- **T+1 制度**：当日买入无法卖出，需特别关注日线级别信号
- **集合竞价**：9:15-9:25 的竞价走势可反映当日多空预期
- **尾盘异动**：14:30 后的急拉/急跌需关注是否有资金刻意操纵
- **北向资金**：北向资金大幅流入/流出对蓝筹股影响显著
