# 投资者交互管理

管理飞书群内投资者的消息识别、意图解析和多轮对话。

## 触发条件

当飞书群内有投资者 @盘古 或发送消息时自动触发。

## 意图识别规则

### 股票代码识别

支持以下格式的股票代码/名称识别：

| 输入格式 | 识别结果 | 说明 |
|---------|---------|------|
| `600519` | 600519.SH | 6 开头默认沪市 |
| `000858` | 000858.SZ | 0 开头默认深市 |
| `300750` | 300750.SZ | 3 开头创业板 |
| `688xxx` | 688xxx.SH | 688 开头科创板 |
| `贵州茅台` | 600519.SH | 名称搜索匹配 |
| `茅台` | 600519.SH | 简称搜索匹配 |
| `SH600519` | 600519.SH | 带市场前缀 |

### 意图分类

| 意图 | 关键词/模式 | 分发目标 | 优先级 |
|------|-----------|---------|--------|
| 股票分析 | "分析/看看/怎么样/怎么看" + 股票 | researcher → strategist | 高 |
| 买入操作 | "买入/买/建仓" + 股票 + 数量 | portfolio-mgr | 高 |
| 卖出操作 | "卖出/卖/清仓/减仓" + 股票 + 数量 | portfolio-mgr | 高 |
| 添加自选 | "加自选/关注/加关注" + 股票 | portfolio-mgr | 中 |
| 删除自选 | "删自选/取消关注" + 股票 | portfolio-mgr | 中 |
| 查看自选 | "自选/我的关注" | portfolio-mgr | 中 |
| 查看持仓 | "持仓/我的股票/仓位" | portfolio-mgr | 中 |
| 查看收益 | "收益/盈亏/赚了多少" | portfolio-mgr | 中 |
| 选股推荐 | "推荐/有什么好股票/热门" | researcher → strategist | 低 |
| 市场行情 | "大盘/行情/今天怎么样" | researcher | 低 |

### 多轮对话场景

#### 场景 1：分析后加自选
```
投资者："帮我分析 600519"
盘古：[返回分析报告]..."是否将 贵州茅台 加入自选？回复'加自选'确认"
投资者："加自选"
盘古：[调用 portfolio-mgr 添加自选]
```

#### 场景 2：分析后买入
```
投资者："帮我分析 002594"
盘古：[返回分析报告 + 买入建议]
投资者："买 200 股"
盘古：[识别上文的 002594，调用 portfolio-mgr 买入]
```

#### 场景 3：数量确认
```
投资者："买入茅台"
盘古："请问买入多少股？（最小单位 100 股）"
投资者："100"
盘古：[调用 portfolio-mgr 买入 600519.SH 100股]
```

## 投资者身份管理

### 首次交互
1. 从飞书消息中提取 sender 的 `open_id`
2. 调用 `portfolio-mgr` 查询是否已注册
3. 如未注册：
   - 提取飞书昵称作为显示名
   - 调用 `portfolio-mgr` 的 `[REGISTER:{open_id}:{name}]`
   - 回复"欢迎加入！已为你开通模拟账户，初始资金 ¥1,000,000"

### 身份缓存
在 `memory/investors.md` 中维护映射表：
```
# 投资者名录

| open_id | 昵称 | 注册日期 | 备注 |
|---------|------|---------|------|
| ou_xxx1 | 张三 | 2026-03-12 | |
| ou_xxx2 | 李四 | 2026-03-12 | |
```

## @提及规则

### 群消息中 @特定投资者

当需要通知特定投资者时（如心跳检测到持仓异动）：
- 在消息开头 @该投资者
- 使用飞书的 `<at user_id="ou_xxx">名称</at>` 格式

### @全员

每日早报和晚报使用 @全员通知。

## 错误处理

| 错误类型 | 回复 |
|---------|------|
| 无法识别股票代码 | "抱歉，未找到'{输入}'对应的股票，请检查代码或名称是否正确" |
| 资金不足 | "可用资金不足，当前可用 ¥{amount}，需要 ¥{required}" |
| 非交易时间 | "当前不在交易时间（9:30-11:30, 13:00-15:00），已记录你的操作，将在下一交易时段执行" |
| 数量不合规 | "买入数量需为 100 的整数倍，已帮你调整为 {adjusted} 股" |
| 无法理解意图 | "抱歉，我没有理解你的意思。你可以试试：\n• 分析 {股票代码}\n• 买入 {股票代码} {数量}股\n• 查看持仓\n• 推荐股票" |
