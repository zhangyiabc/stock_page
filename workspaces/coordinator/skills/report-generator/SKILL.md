# 早报/晚报生成器

生成结构化的每日早报和晚报，适配飞书群消息格式。

## 触发条件

- 收到 `[CRON:MORNING_BRIEF]` 时生成早报
- 收到 `[CRON:EVENING_REPORT]` 时生成晚报

## 格式规范

### 飞书消息限制
- 单条消息建议控制在 2000 字符以内
- 超长内容拆分为多条消息发送
- 使用 Unicode 符号（━、▍、•）代替 Markdown（飞书群消息中 Markdown 渲染有限）

### 数字格式
- 金额：¥1,234,567.89（千分位逗号）
- 百分比：+2.35% 或 -0.45%（带正负号）
- 股数：100 股（无千分位）
- 日期：YYYY-MM-DD

### 色彩标注（飞书支持 emoji 代替颜色）
- 上涨/正面：📈 或无特殊标记（飞书文字无颜色）
- 下跌/负面：📉
- 中性/提醒：⚠️
- 板块标记：🔵
- 排名：🥇🥈🥉

## 异常处理

- 如果数据获取失败，在对应位置标注"数据暂不可用"
- 如果没有投资者持仓，晚报中排行榜部分替换为"暂无持仓记录"
- 如果没有交易操作，操作回顾部分替换为"今日无操作记录"
- 法定节假日不发送报告（由 cron 的工作日过滤处理）
