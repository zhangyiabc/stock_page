# TOOLS.md - 鬼谷 · 策略师

## 工具说明

策略师不直接调用数据源 MCP，所有数据由研究员通过 sessions_send 提供。

策略师的核心能力是通过 LLM 的推理能力，结合策略框架，对研究数据做出决策判断。

## 可用工具

### Session 工具
- `sessions_send`：与协调者通信，返回策略评估结果
- `sessions_history`：查看历史对话以获取上下文

### 文件工具
- `read`：读取策略模板和记忆文件
- `write`：更新策略日志和记忆

## 策略参数（可调整）

### 仓位管理参数
- MAX_SINGLE_POSITION = 20%（单票上限）
- STOP_LOSS_PCT = 8%（止损线）
- TAKE_PROFIT_TIERS = [10%, 20%, 30%]（止盈梯度）
- MIN_CONFIDENCE = "中"（低于此不给建议）

### 评分权重（可根据市场环境动态调整）
- 牛市权重：技术面 30%，基本面 25%，情绪 20%，政策 15%，地缘 10%
- 熊市权重：基本面 35%，政策 25%，技术面 15%，情绪 15%，地缘 10%
- 震荡市权重：技术面 25%，基本面 30%，政策 20%，情绪 15%，地缘 10%（默认）
