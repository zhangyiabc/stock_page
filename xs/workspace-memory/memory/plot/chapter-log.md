# 章节摘要 —— 全局索引

## 使用说明

章节摘要按卷分片存储，每卷独立一个文件。本文件是索引入口。

**写入规则：**
- 每章摘要写入对应卷的分片文件 `chapters/vol{N}-chapters.md`
- 新开一卷时，创建新的分片文件
- 本索引文件只记录元信息，不存储摘要正文

**查询规则：**
- 查"最近 N 章摘要"→ 读取当前卷分片文件的末尾 N 条
- 跨卷查询 → 读取当前卷 + 上一卷分片文件
- 查特定章节 → 根据章节号定位卷，读取对应分片
