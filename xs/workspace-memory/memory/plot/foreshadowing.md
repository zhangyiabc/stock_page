# 伏笔追踪 —— 全局索引

## 使用说明

伏笔数据按状态分文件管理，避免单文件膨胀。

**文件结构：**
- `foreshadowing.md`（本文件）：全局索引 + 活跃伏笔汇总
- `foreshadowing/archived.md`：已回收 + 已废弃的伏笔归档
- `foreshadowing/vol{N}-planted.md`：按卷记录的伏笔埋设详情

**写入规则：**
- 新伏笔同时写入本文件的"活跃伏笔"表和对应卷的 `vol{N}-planted.md`
- 伏笔回收后，从"活跃伏笔"表移除，转入 `archived.md`
- 活跃伏笔表控制在合理大小（预期 30~80 条）

**查询规则：**
- 查当前活跃伏笔 → 读本文件
- 查已回收的历史伏笔 → 读 `archived.md`
- 查某卷埋设的所有伏笔 → 读 `vol{N}-planted.md`

## 伏笔类型说明

- `物品`：与特定物品相关的伏笔
- `人物`：与角色身份/过去相关的伏笔
- `事件`：与某个未来事件相关的伏笔
- `设定`：与世界观规则相关的伏笔
- `情感`：与角色关系/情感发展相关的伏笔
