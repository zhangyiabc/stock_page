# 故事内时间线 —— 全局索引

## 使用说明

时间线按卷分片存储，避免单文件膨胀。

**文件结构：**
- `timeline.md`（本文件）：全局索引 + 时间跨度统计 + 跨卷关键节点
- `timelines/vol{N}-timeline.md`：按卷的详细时间线事件

**写入规则：**
- 每章的事件写入当前卷的分片文件
- 跨卷的重大时间节点同时记录在本文件的"关键节点"表中

**查询规则：**
- 查当前卷的时间线 → 读取对应分片
- 查全局时间跨度 → 读本文件
- 需要精确时间对照 → 读取相关的多个分片
