# 角色设计方法论

角色不是"人设标签"，而是 **功能 + 欲望 + 特点 + 关系 + 变化** 的组合。

## 角色设计六步法

**第一步：先确定故事功能**
先问"这个角色在故事里干什么"，再设计其他。同一个"师姐"可以是保护者、竞争者、感情对象、中期背刺者、引路人——功能不同，设计完全不同。没有功能的角色就是废角色。

**第二步：给核心欲望**
角色必须"想要什么"才能活。常见欲望：生存、变强、复仇、权力、认同、自由、真相、守护。欲望决定了角色为什么出场、为什么卷入冲突、为什么跟主角纠缠。没有欲望的角色只会站着说话，像工具人。

**第三步：给鲜明特点**
不是"高冷""温柔"这种空词，而是别人一看就能分辨的行为气质。从三个方向设计：
- **行为特点**：说话少但每句都重 / 嘴毒但护短 / 吊儿郎当实则观察细 / 先算收益再动手
- **情绪特点**：容易炸 / 极能忍 / 爱逞强 / 控制欲强 / 内心柔软但不肯表现
- **价值观特点**：只信自己 / 认死理 / 极重承诺 / 崇尚强者法则 / 有些底线绝不能破

**一个角色最好只有 1 个最突出的强特点**，不要同时塞太多标签。

**第四步：设计矛盾感**
单一标签容易扁平，给角色一点"统一中的反差"让他像活人：嘴硬心软 / 表面正派实际很会算计 / 看着疯实则很清醒 / 明明很强却极度自卑 / 表面爱钱最重情义。注意："嘴毒但护短"是矛盾感，"前一章仁慈后一章无故滥杀"是崩人设。

**第五步：设计和主角的关系张力**
角色好不好写，关键在于和主角之间有没有张力。从四个维度设计：
- 利益关系：合作 / 竞争 / 互相利用 / 交易
- 情感关系：信任 / 崇拜 / 嫉妒 / 依赖 / 怨恨
- 立场关系：同阵营 / 敌对 / 表面同阵营实则有私心
- 观念关系：认同主角 / 挑战主角价值观 / 成为主角的另一种可能

关系越复杂戏越多："她既是盟友又竞争同一个机会""他既欣赏主角又想击败主角""师父真心教但隐瞒了关键真相"。

**第六步：给出场目的和变化方向**
- 出场目的：不是"很酷所以安排一下"，而是给主角制造阻碍 / 揭开设定 / 推动感情线 / 带入下一阶段
- 变化方向：重要角色最好有弧光——从轻视到认可 / 从利用到伙伴 / 从复仇者到发现更大真相 / 从理想主义到黑化

## 角色必答八问

每个重要角色至少回答：
1. 他是谁？
2. 他想得到什么？
3. 他最怕失去什么？
4. 他最明显的特点是什么？
5. 他和主角是什么关系？
6. 他第一次出场要起什么作用？
7. 他会制造什么冲突或提供什么帮助？
8. 他最终会变成什么样？

## 不同类型角色的设计重点

**主角**：必须有强欲望、鲜明优势（金手指）、缺点/代价、代入感。强得让人想看，难得让人担心。

**反派**：必须有真实欲望（不是纯坏）、有自己的逻辑（不是随机发疯）、能对主角构成压力（能力/资源/智谋至少占一项）、能逼出主角的变化。反派太蠢，主角赢了也不爽。

**配角**：至少给三样——一个明显特点、一个明确功能、一个和主角的独特连接点。不需要写得像文学主角，但要做到：清晰、好记、有用、有戏。

## 角色设计常见错误（必须避免）

- **只有标签没有动机**："高冷校花""腹黑王爷"太空，必须补上"为什么"
- **只有设定没有功能**：身世悲惨、天赋很高、有个秘密，但对剧情没用 = 白设定
- **所有人说话都一样**：语言节奏、用词习惯、情绪表达必须有区分
- **强行复杂**：普通配角不需要三层人格五段创伤，清晰有用就够了
