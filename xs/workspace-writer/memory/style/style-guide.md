## 段落节奏

- 动作场景：短句为主（5-15字），段落紧凑，大量使用动词
- 情感场景：长短句交错，段落舒展，允许大段留白
- 描写场景：中等句长，注重意象，禁止超过3句连续纯描写
- 对话场景：对话占比 60-70%，穿插动作和神态，神态不用"XX地说"
- 爽点爆发场景：画面感拉满，节奏加速，动词密集，不要在高潮处突然文艺化
- 压力积蓄场景：适度放慢但不能无聊，每一段都要有信息量或情绪推进

## 网文节奏模板

### 标准章节节奏（约8000-10000字/章）

一章的典型情绪走向应该是一条有波动的曲线，而不是平线：

```
高 ·                    ·  ← 章内高潮
   ·                   / \
情  ·        ·        /   · ← 章末钩子（不要回落）
绪  ·       / \      /
    ·      /   \    /
     ·    /     ·--·  ← 适当的节奏回落
低    ·--· ← 开场（接上一章钩子）
```

### 爽点密度控制

| 时间跨度 | 爽点级别 | 要求 |
|---|---|---|
| 每1-2章 | 微爽 | 至少一个"事情在推进"的感觉：获得信息、小胜利、关系推进 |
| 每3-5章 | 小爽 | 一次明确的打脸/升级/逆袭/捡漏 |
| 每5-8章 | 中爽 | 一个小高潮弧线完成（压力-爆发-收获完整循环） |
| 每15-20章 | 大爽 | 卷级高潮——大战/大反转/身份曝光/地位跃升 |

**核心原则：连续3章无任何推进感 = 失败**

### 章末钩子（每章必须）

章末绝对不能"平着结束"。以下是禁止的章末方式：
- "主角回家睡觉了。"
- "今天就先这样。"
- 主角安全地完成了事情，一切平静
- 总结式/感悟式/鸡汤式段落

以下是好的章末钩子模式：
- 悬念未解：真相只揭开一半
- 新危机降临：敌人出现/阴谋暴露
- 奖励即将兑现：读者期待看到收益
- 关键人物登场：改变格局的人出现
- 关系突变：感情线出现转折
- 战斗断章：打到最紧张处戛然而止

### 开篇特殊要求（前3章）

前3章是生死线，必须做到：
- 第1章直接进入冲突/危机，不做冗长世界观介绍
- 前3章内必须交代：主角是谁、遇到什么麻烦、有什么特别、为什么值得继续看
- 金手指/优势最迟第3章出现或暗示
- 不要用大段旁白介绍世界观，通过角色体验自然展现

## AI 味检测词汇黑名单

以下词汇/表达在 AI 生成文本中出现频率极高，是读者识别"AI味"的核心线索。
标注为「禁用」的零容忍；标注为「限用」的每章不超过标注次数。

### 禁用（出现即改）

| 类别 | 词汇/表达 |
|---|---|
| 情绪套路 | 内心深处、心中涌起、心头一震/一紧/一沉、一股暖流/寒意涌上 |
| 眼睛万能 | 眼中闪过一丝XX、目光中带着XX、眼神变得深邃/柔和 |
| 嘴角运动 | 嘴角微微上扬、勾起一抹弧度、嘴角挂着一丝不易察觉的微笑 |
| XX之色 | 震惊之色、玩味之色、惊恐之色（所有"之色"构式） |
| 时间暂停 | 时间仿佛凝固/静止了、那一刻世界安静了 |
| 空气描写 | 空气中弥漫着XX的气息/味道、空气变得凝重 |
| 鸡汤结尾 | 也许这就是XX、或许命运早已注定、这一刻他明白了 |
| 全知泄露 | 他不知道的是、如果他能预见到、殊不知 |
| 虚假文艺 | 岁月静好、浅浅的微笑、温柔地注视着一切 |

### 限用（每章上限）

| 词汇/表达 | 上限 | 替代建议 |
|---|---|---|
| 不禁/不由得/忍不住 | 1次 | 直接写动作 |
| 缓缓 | 1次 | 用具体动作表现速度感 |
| 仿佛/宛如/恰似 | 合计2次 | 直接用"是"或取消比喻 |
| 然而（段落开头） | 1次 | 用"但"、"可"，或取消转折词直接转 |
| 就在这时 | 1次 | 直接写后续事件 |
| 突然 | 1次 | 用动作的突兀感来体现 |
| 微微 | 2次 | 找准确的形容词 |

## 句式反模式

以下是 AI 偏爱但人类作家很少使用的句式，必须规避：

1. **三连排比**："他看到了A，看到了B，看到了C" → 最多两项并列
2. **匀速段落**：连续3段以上每段4-6句、每句15-25字 → 刻意变化段落长度
3. **同构开头**：连续段落以相同结构开头（"他XXX。他YYY。他ZZZ。"）→ 变换主语和句式
4. **解释性叙述**：动作后紧跟心理解释（"他握紧拳头——他太愤怒了"）→ 砍掉解释，让动作自己说话
5. **形容词堆叠**：一个名词前超过2个形容词 → 最多1个，用动词化描写替代
6. **完美对话**：每句对话都是完整语法正确的句子 → 加入省略、打断、口癖

## 每章自检清单

写完每章后，writer 必须自行过一遍以下检查，不合格的自行修改后再提交：

### AI 味检查
- [ ] 全文搜索禁用词汇表，确认零命中
- [ ] 限用词汇是否超出上限
- [ ] 是否存在连续3段以上的匀速节奏
- [ ] 对话是否过于书面化，是否有省略和不完整句
- [ ] 章末是否有总结/感悟/升华式段落（如有则删除）
- [ ] 比喻是否是专门为本场景设计的，还是套路比喻
- [ ] 同一页内是否有视角跳跃（第三人称有限视角下）

### 网文质量检查
- [ ] 本章是否有明确的"推进感"（剧情/能力/关系至少一项在前进）
- [ ] 大纲中设计的爽点是否写到位了（压得够狠、爆得够爽）
- [ ] 章末是否有有效的钩子（不是平着结束的）
- [ ] 本章提供了什么情绪价值（爽/燃/甜/虐/悬疑 至少一种）
- [ ] 是否有超过连续2章的内容无冲突/无悬念/无进展
- [ ] 对话中是否有角色为了给读者解释设定而不自然地说出信息（信息倾倒）
- [ ] 如果是前3章：开篇是否直接进入冲突，金手指是否出现或暗示
